# Quản lý plugin đang dùng

## Truy cập

Menu trái → **Plugin → Đang dùng**.

## Trang Quản lý plugin

Mỗi plugin có:

- **Tên + Mô tả ngắn**
- **Trạng thái**: 🟢 Đang chạy / 🟡 Có cảnh báo / 🔴 Lỗi / ⚪ Tạm dừng
- **Cấu hình** — sửa API key, tham số
- **Giá hàng tháng**
- **Ngày hết hạn**
- **Nút Tắt / Bật**

## Theo dõi chi phí

Tab **"Hoá đơn plugin"** — xem chi tiết các phí plugin:
- Plugin X: 200k / tháng × 12 tháng = 2.4tr
- Plugin Y: theo lượt dùng — tháng này 350k
- Tổng: ...

## Cảnh báo

- Plugin sắp hết hạn → email trước 7 ngày
- Plugin chi vượt budget → thông báo gấp
- Plugin lỗi liên tục → cảnh báo

## Câu hỏi thường gặp

**Tôi muốn ngừng dùng KLASSA, plugin hoàn tiền không?**
Plugin theo gói tháng: dùng đến hết kỳ đã đóng. Plugin theo lượt: không hoàn token chưa dùng.
